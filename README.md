# SignalR Chat Demo

[![.NET](https://img.shields.io/badge/.NET-8.0-512BD4?logo=dotnet)](https://dotnet.microsoft.com/)
[![SignalR](https://img.shields.io/badge/SignalR-8.0.4-FF6F00?logo=microsoft)](https://dotnet.microsoft.com/apps/aspnet/signalr)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Простой, но функциональный демонстрационный веб-чат в реальном времени, построенный на технологии **ASP.NET Core SignalR**. Проект служит наглядным примером для изучения основ двусторонней (client-server) коммуникации.

## 📋 Что это за проект?

Это демонстрационное приложение чата, где пользователи могут:
*   Подключаться к общему чату, вводя свое имя.
*   Отправлять текстовые сообщения всем подключенным пользователям в реальном времени.
*   Видеть мгновенное обновление списка участников при подключении или отключении других пользователей.

**Цель проекта:** Показать базовые возможности SignalR (хаб, методы, вызовы) в чистом виде, а затем поэтапно развить его до полноценного многокомнатного чата с расширенной функциональностью.

## 🚀 Как запустить

### Предварительные требования
*   [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или новее.
*   Любая среда разработки (Visual Studio 2022, VS Code, Rider) или командная строка.

### Шаги для запуска
1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/ZodiacMLG/SignalRChatDemo.git
    cd SignalRChatDemo
    ```

2.  **Запустите сервер:**
    ```bash
    cd src/Server
    dotnet run
    ```
    Сервер запустится на `https://localhost:****` и `http://localhost:****`. (Порт будет указан при запуске сервера)

3.  **Запустите клиент:**
    *   Откройте новый терминал и перейдите в папку клиента:
    ```bash
    cd src/Client
    dotnet run
    ```
    
4.  **Начните общение:**
    *   Введите имя пользователя в клиенте.
    *   Отправьте сообщение - оно появится у всех подключенных пользователей.

## 📌 План развития (Roadmap)

Проект находится в активной разработке. Планируемые улучшения и новые функции:

### 🔄 **Этап 1: Рефакторинг и структура**
*   ✅Четкое разделение решения на проекты: **Сервер (Server)**, **Веб-клиент (Client)**, **Общие библиотеки (Shared Libraries)**.
*   ✅Улучшение организации кода для лучшей масштабируемости.

### 🚪 **Этап 2: Основные функции чата**
*   ✅**Комнаты/Каналы:** Возможность создавать новые комнаты и присоединяться к существующим.
*   **История сообщений:** Хранение истории сообщений комнаты (сначала в памяти, затем переход на постоянное хранилище).
*   ✅**Система команд в чате:** Обработка специальных команд, начинающихся с `/` (например, `/join room1`, `/users`, `/help`).
*   ✅**Простая аутентификация:** Фиксация имени пользователя при входе в систему.

### 📝 **Этап 3: Надежность и наблюдение**
*   **Логирование (Logging):** Внедрение структурированного логирования на сервере для отслеживания подключений, ошибок и активности чата.

### 🔮 **Будущие возможности (в перспективе)**
*   **Постоянное хранилище:** Интеграция с базой данных (например, SQLite, PostgreSQL) для сохранения истории сообщений и пользователей.
*   **Приватные сообщения.**
*   **Уведомления.**
*   **Файлообмен.**
